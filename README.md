# 超级马里奥 · 极速跑酷

一个不需要构建、打开即玩的 HTML5 马里奥风无尽跑酷小游戏。只保留重制版，分 **简单 / 普通 / 困难 / 极限** 四档；头像来自独立文件夹，支持自定义昵称、54 个里程碑成就、排行榜和全新障碍。当前版本 **v0.4.1**。

## 直接开始

双击 `index.html`，用现代浏览器（Chrome / Edge / Safari / Firefox）打开即可。

- 主界面采用三栏布局：左侧排行榜/成就卡片，中间游戏标题、难度和开始按钮，右侧角色选择。
- 主界面先选模式：**简单 / 普通 / 困难 / 极限**。
- 桌面端：`空格` 或 `↑` 跳跃，空中再按一次二段跳；`P` / `Esc` 暂停；`M` 静音。
- 手机端：点击右下角的大跳跃键；空中再点一次二段跳。
- 竖屏、横屏都会直接显示游戏页面，不再弹出横屏提示。
- 主界面点「更换头像」会打开 `avatars.html` 选择页；第一次进入会要求设置昵称，昵称会显示在角色头顶。

## 模式与数值

| 模式 | 最高速度 | 跳跃高度 | 金币回心 | 心数 | 问号砖 |
| --- | --- | --- | --- | --- | --- |
| 简单 | 570 px/s | 原始高度的 100% | 20 枚 | 3 | 25% 回心 / 75% 随机分 |
| 普通 | 700 px/s | 原始高度的 95% | 30 枚 | 3 | 25% 回心 / 75% 随机分 |
| 困难 | 805 px/s（普通 ×1.15） | 普通高度的 97%（约原始 92.15%） | 60 枚 | 3 | 25% 回心 / 75% 随机分 |
| 极限 | 805 px/s | 普通高度的 97%（约原始 92.15%） | 不回血 | **1** | 25% 回心（满血时转随机分） |

- 踩中小怪：地面小怪第一次 **1000 分**，飞行小怪第一次 **5000 分**，之后按连击倍数增加。
- 踩踏判定看竖直方向速度：下落速度达到 **180 px/s** 及以上才算踩中；速度过低、为 0 或正在上升时撞到小怪会扣血。
- 同时踩到多只叠在一起的小怪会全部算踩中，不会再因为第一只的反弹而误扣血；同一帧同时踩中 2 只可解锁「一箭双雕」。
- **简单模式不生成任何小怪和地刺**，只保留水管、深坑、砖块与金币。
- **普通模式有地面小怪和地刺，但没有飞行小怪**。
- 困难/极限模式保留全部障碍：地面小怪、飞行小怪、地刺。
- 地面小怪基础速度 18~30 像素/秒，按模式加速：简单 ×1.5（27~45，但简单不生成小怪）、普通 ×2（36~60）、困难/极限 ×2.5（45~75）；实际接近玩家的速度还要加上玩家跑速。
- 地面小怪会随机向左或向右巡逻；接近深坑边缘时会自动掉头，不会走进坑里。
- 距离分：每跑 1 米 **20 分**（每世界像素 1 分）。
- 简单模式：570 速度、20 币回心、100% 跳跃、1.75 秒受伤无敌。
- 普通模式：700 速度、30 币回心、95% 跳跃、1.225 秒受伤无敌。
- 困难：805 速度、60 币回心、92.15% 跳跃、0.8 秒无敌；问号砖保留 25% 一等奖回心。
- 极限模式全程只有 1 颗心，任何一次受伤都会直接结束；因为始终满血，问号砖一等奖会自动转成随机分；受伤无敌同样为 0.8 秒。
- 无敌期间掉进深坑会直接回到地面，不扣心、不刷新无敌时间。

## 新增障碍

- **地刺**：地面上的静态障碍，碰到扣心，跳过去即可。
- 地面小怪遇到管道或地刺会掉头，不会直接穿过去。
- **飞行小怪**：在空中按正弦轨迹飞行，可以踩；踩中同样计入 1000×连击分。只在困难/极限出现，生成概率已降为原来的一半。

## 成就

主界面左侧「成就」卡片打开成就页。**四档模式通用一套成就，共 54 个**，分为 **3 个一级类别 → 9 个二级分类 → 成就条目**；第一次达到条件即永久解锁，并记录达成时间：

- **征程（19）**：分数（4）、距离（3）、旅程（12）。
  - 分数：50,000、100,000、500,000、1,000,000 分。
  - 距离：21 公里、42 公里、100 公里。
  - 旅程：四模式局数/距离/排名、累计局数/金币/踩怪/二段跳/距离等。
- **冒险（21）**：战斗（9）、空中（7）、生存（5）。
  - 战斗：踩中、连击、双踩、单次踩怪高分、地面/飞行踩怪等。
  - 空中：二段跳、跳跃次数、滞空时间、空中连踩、不落地连跳等。
  - 生存：连续受伤、回心后立刻掉心、离屏、特殊死亡、无伤等。
- **机缘（14）**：金币（7）、奇趣（6）、殿堂（1）。
  - 金币：单局金币、回心次数、差点回心、低金币通关等。
  - 奇趣：昵称修改、快速重开、暂停、时段完成、清理本机数据。
  - 殿堂：解锁其他全部 53 个成就后获得「功德圆满」。

普通成就会全部显示在导图中；**未解锁的名称显示为「？？？」，但图标和详细说明仍可查看**。14 个隐藏成就在解锁前显示问号图标，名称、说明和提示都显示为「？？？」，解锁后才显示真实内容。

旧版按模式分开的成就会自动合并成一套通用成就，同一条成就保留最早解锁时间。成就和达成时间默认保存在本机浏览器；登录微信后也会同步到云端账号。

成就页为三级横向思维导图：最左列是「征程 / 冒险 / 机缘」三个一级类别，中间列是 9 个二级分类，右侧列是正方形成就图标；不再保留额外的通用「成就」根节点。鼠标悬浮、键盘聚焦或点击图标时显示名称（未解锁时为「？？？」）、详细说明和解锁状态。解锁成就时会从右上角弹出带图标和成就颜色的提示，并播放普通或挑战成就音效；挑战成就有 25 个。

完整的 54 项成就名称、条件、分类、难度和隐藏标记见 [成就表-v0.4.0.md](成就表-v0.4.0.md)。问号砖单次奖励为 500–1500 分；单次获得 1451 分以上时解锁「幸运暴击」。

## 头像

- 所有预设头像已移除，头像统一来自 `avatars/` 文件夹。
- 直接打开 `avatars.html` 可以预览、选择头像；也可以从游戏主界面点「更换头像」打开。
- 浏览器不能自动扫描本地文件夹，所以：
  1. 在 `avatars/manifest.js` 里登记图片（适合部署到 GitHub Pages），或
  2. 在 `avatars.html` 里点「从文件夹导入」，选择 `avatars/` 文件夹（适合本地使用）。
- 导入的图片会压缩后保存在本机浏览器里；也可以直接「上传一张照片」。

## 昵称

- 每台设备第一次进入会要求输入一个**昵称**；之后跑步时昵称会显示在角色头顶，排行榜也只显示昵称。
- 昵称设置后可以点首页左上角放大的「昵称」按钮修改。
- **昵称在 30 天内最多修改 2 次**；首次设置不计入修改次数。
- 设置/修改昵称的弹窗会显示剩余修改次数和警告；次数用完后会显示下一次可修改的日期，并禁止继续保存。
- 修改次数记录在本机浏览器；清除浏览器数据会重置这个本地限制。

## 微信登录（可选）

- 设置页新增「微信账号」区域。登录后可把 **昵称、头像、成就、统计** 同步到云端，并在其他设备上恢复。
- 第一次登录时，如果本机和云端都有资料，会询问保留哪一份；不会自动覆盖。之后同一账号打开会自动使用云端资料。
- 两台设备同时修改时使用版本冲突提示，由你选择「使用云端最新」或「用本机资料覆盖」。
- 微信登录需要微信开放平台「网站应用」和 Supabase Edge Functions；没有配置时保持未登录，本机游戏和排行榜不受影响。
- 配置和上线步骤见 [微信登录接入步骤.md](微信登录接入步骤.md)。
- 后端文件在 `supabase/migrations/` 和 `supabase/functions/`；需要单独部署，GitHub Pages 本身不运行后端。
- AppSecret 只保存在 Supabase Secrets，前端只使用 publishable key。

## 操作与其它

- 头像、昵称、模式、最高分、成就和本机排行榜默认保存在当前浏览器本地；登录微信后可同步到云端账号。
- 成就的累计类条件会使用跨局统计：完成局数、累计金币、累计踩怪、累计二段跳、累计距离，以及四个难度各自的局数、最佳距离、本机前 10 和全球前 10 记录；这些统计默认保存在本机，登录微信后可同步。
- 排行榜分为「本机」和「全球」：本机只保存在当前浏览器；全球榜通过 Supabase 同步，同一网址下所有设备看到同一份记录。每个难度统一显示前 **200** 名，当前局排名固定在列表底部。全球榜默认显示「每人最佳」，也可切换为「全部记录」。
- 背景由 `css/background.css` 和 `js/background.js` 提供天空/云/雪山/近景多层视差；山峰使用 `assets/snow-bg.jpg`，云、鸟、树和前景仍为独立层；默认跟随难度切换白天、黄昏或夜空，也可以在设置里锁定主题或开启「减少动态效果」。
- 本次更新会清空一次本机排行榜和最高分；全球榜通过新的记录时间起点隐藏旧记录，旧数据仍保留在数据库中。要彻底删除旧全球记录，可在 SQL Editor 运行：
  `delete from public.scores;`
- 每局结束会先写入本机，再自动尝试上传到全球榜；断网或上传失败时会进入待同步队列，下次打开排行榜/重新进入游戏时自动重试。
- 更新前已经存在的本机旧成绩不会自动上传；从这次更新后的新对局开始进入全球榜。
- 如果所在网络无法访问 `supabase.co`，全球榜会显示连接失败，切换到「本机」仍可查看本地成绩。
- 全球榜记录昵称、模式、分数、金币、距离、用时与日期；最高分仍按模式保存在本机。
- 无敌期间掉坑、地刺、飞行小怪等规则与普通小怪一致；困难/极限的受伤与回地无敌都是 0.8 秒。
- 所有场景、角色、金币、障碍和 UI 都是代码绘制的；头像除外。
