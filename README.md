# 超级马里奥 · 极速跑酷

一个不需要构建、打开即玩的 HTML5 马里奥风无尽跑酷小游戏。主界面可以选「怀旧版」或「重置版（简单 / 困难）」，主角的头像可以随时更换，也可以上传自己的照片；每一局的分数和用时都会记进主界面的排行榜。

## 直接开始

双击 `index.html`，用现代浏览器（Chrome / Edge / Safari / Firefox）打开即可。

- 主界面先选版本：**怀旧版**保持原版规则，**重置版**再选**简单**或**困难**。
- 桌面端：`空格` 或 `↑` 跳跃，空中再按一次二段跳；`P` / `Esc` 暂停；`M` 静音。
- 手机端：横屏游玩，点击右下角的大跳跃键；空中再点一次二段跳。
- 主菜单和暂停菜单都可以换跑者。选择最后一格可上传照片，照片会变成游戏里主角的头。
- 主界面右上角「排行榜」可以查看所有历史成绩。

## 玩法

- 自动向前奔跑，跳过水管、深坑和板栗仔。
- 从上方踩中板栗仔可以得分，并在 2.7 秒内连续踩怪累计连击。
- 掉进深坑或撞到敌人会消耗一颗心，共有 3 颗心；深坑会将你送回前方安全地面。
- 速度会随着距离和时间逐渐加快，达到该模式的上限后保持恒定。
- 最高分、头像、版本选择和声音偏好都会保存在当前浏览器本地。

## 版本与数值

| 版本 | 踩怪奖励 | 问号砖 | 回血 | 最高速度 |
| --- | --- | --- | --- | --- |
| 怀旧版 | 原版 `160 + 90 × 连击` 分 | +1 金币、+120 分 | 30 枚金币 | 570 px/s |
| 重置版 · 简单 | `500 × 连击` 分 | +1000 ~ 5000 随机分 | 30 枚金币 | 570 px/s |
| 重置版 · 困难 | `500 × 连击` 分 | +1000 ~ 5000 随机分 | 50 枚金币 | 700 px/s |

- 所有模式都从 330 px/s 起步，按「330 + 0.012 × 已跑像素 + 1.2 × 已跑秒数」加速：怀旧版 / 简单约 37 秒触顶，困难约 52 秒触顶。
- 重置版里问号砖只给随机分，不再额外给金币。
- 怀旧版的玩法数值与原版完全一致。

## 排行榜

- 每局结束自动记录：**分数、游玩时间**、距离、金币、模式与日期。
- 主界面右上角「排行榜」打开，可按「全部 / 怀旧版 / 简单 / 困难」筛选；最高分也按模式分别保存。
- 记录保存在浏览器 `localStorage`（最多 300 条），连点两次「清空记录」即可确认清空，不会上传到任何服务器。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、版本/难度选择、排行榜弹层、HUD |
| `styles.css` | 菜单、卡牌、弹窗、排行榜、响应式布局 |
| `game.js` | Canvas 场景、角色绘制、跑酷物理、规则分流、音效、头像与排行榜逻辑 |
| `previews/` | 菜单、游戏、暂停与排行榜效果图 |

所有场景、角色、金币、水管和 UI 都是代码绘制的，没有图片或字体等外部依赖，离线可用。

## 小提示

- 上传照片时会在浏览器内自动居中裁剪成头像，不会上传到任何服务器。
- 上传后，再次点击“我的头像”卡片即可替换照片。
- 手机竖屏时会提示旋转设备，横屏才能看清整条跑道。
- 切换版本/难度后按 `空格` 即可直接开跑；排行榜记录的是实际游玩时间，暂停不计入。
