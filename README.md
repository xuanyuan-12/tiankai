# 超级马里奥 · 极速跑酷

一个不需要构建、打开即玩的 HTML5 马里奥风无尽跑酷小游戏。只保留重制版，分 **简单 / 普通 / 困难 / 极限** 四档；头像来自独立文件夹，支持自定义昵称、里程碑成就、排行榜和全新障碍。

## 直接开始

双击 `index.html`，用现代浏览器（Chrome / Edge / Safari / Firefox）打开即可。

- 主界面采用三栏布局：左侧排行榜/成就卡片，中间游戏标题、难度和开始按钮，右侧角色选择。
- 主界面先选模式：**简单 / 普通 / 困难 / 极限**。
- 桌面端：`空格` 或 `↑` 跳跃，空中再按一次二段跳；`P` / `Esc` 暂停；`M` 静音。
- 手机端：点击右下角的大跳跃键；空中再点一次二段跳。
- 竖屏、横屏都会直接显示游戏页面，不再弹出横屏提示。
- 主界面点「更换头像」会打开 `avatars.html` 选择页；第一次进入会要求设置昵称，昵称会显示在角色头顶。

## 模式与数值

| 模式 | 最高速度 | 跳跃高度 | 金币回心 | 心数 | 问号砖 |
| --- | --- | --- | --- | --- | --- |
| 简单 | 570 px/s | 原始高度的 100% | 30 枚 | 3 | 25% 回心 / 75% 随机分 |
| 普通 | 700 px/s | 原始高度的 95% | 50 枚 | 3 | 25% 回心 / 75% 随机分 |
| 困难 | 805 px/s（普通 ×1.15） | 普通高度的 97%（约原始 92.15%） | 100 枚 | 3 | 25% 回心 / 75% 随机分 |
| 极限 | 805 px/s | 普通高度的 97%（约原始 92.15%） | 不回血 | **1** | 25% 回心（满血时转随机分） |

- 踩中小怪：地面小怪第一次 **1000 分**，飞行小怪第一次 **5000 分**，之后按连击倍数增加。
- 踩踏判定看竖直方向速度：下落速度达到 **180 px/s** 及以上才算踩中；速度过低、为 0 或正在上升时撞到小怪会扣血。
- 同时踩到多只叠在一起的小怪会全部算踩中，不会再因为第一只的反弹而误扣血。
- **简单模式不生成任何小怪和地刺**，只保留水管、深坑、砖块与金币。
- **普通模式有地面小怪和地刺，但没有飞行小怪**。
- 困难/极限模式保留全部障碍：地面小怪、飞行小怪、地刺。
- 地面小怪基础速度 18~30 像素/秒，按模式加速：简单 ×1.5（27~45，但简单不生成小怪）、普通 ×2（36~60）、困难/极限 ×2.5（45~75）；实际接近玩家的速度还要加上玩家跑速。
- 地面小怪会随机向左或向右巡逻；接近深坑边缘时会自动掉头，不会走进坑里。
- 距离分：每跑 1 米约 **11 分**（每世界像素 0.55 分）。
- 简单模式：570 速度、30 币回心、100% 跳跃、1.75 秒受伤无敌。
- 普通模式的数值沿用原来的“困难”：700 速度、50 币回心、95% 跳跃、1.225 秒受伤无敌。
- 困难：805 速度、100 币回心、92.15% 跳跃、0.8 秒无敌；问号砖保留 25% 一等奖回心。
- 极限模式全程只有 1 颗心，任何一次受伤都会直接结束；因为始终满血，问号砖一等奖会自动转成随机分；受伤无敌同样为 0.8 秒。
- 无敌期间掉进深坑会直接回到地面，不扣心、不刷新无敌时间。

## 新增障碍

- **地刺**：地面上的静态障碍，碰到扣心，跳过去即可。
- 地面小怪遇到管道或地刺会掉头，不会直接穿过去。
- **飞行小怪**：在空中按正弦轨迹飞行，可以踩；踩中同样计入 1000×连击分。只在困难/极限出现，生成概率已降为原来的一半。

## 成就

主界面左侧「成就」卡片打开成就页。**四档模式通用一套成就，共 16 个**，不再按模式分开；第一次达到条件即永久解锁，并记录达成时间：

**分数**：`50,000`（小试牛刀）、`100,000`（十万分）、`500,000`（一骑绝尘）、`1,000,000`（登峰造极）分。

**连击**：`见鬼去吧`（连续踩中 1 只小怪）、`五连绝世`（连续踩中 5 只小怪）、`天赐良机`（连击 10 只小怪，隐藏）。

**幸运**：`幸运暴击`（问号砖单次获得 4,900 分及以上）、`物超所值`（在问号砖里获得回一颗心的奖励）。

**伤害/生存**：`天煞孤星`（4 秒内连续受到 3 次伤害）、`超越生死`（1 心时回到 2 心后 1 秒内又掉心）、`这上面的风景不错`（身体完全超出屏幕外）、`上天入地`（离屏后掉入深坑死亡，隐藏）。

**距离**：`半马选手`（21 公里）、`新的全马世界纪录!`（42 公里）、`热门景点`（100 公里，隐藏）。

旧版按模式分开的成就会自动合并成一套通用成就，同一条成就保留最早解锁时间。成就和达成时间保存在本机浏览器，不会上传。

成就页已改为思维导图：左侧「成就」根节点分出分数、距离、连击、幸运、生存五条分支，节点之间用连线连接。每个成就使用正方形图标；未解锁的非隐藏成就只显示图标，悬浮/聚焦时显示详细说明，解锁后才显示名称和日期。解锁时会从右上角弹出带图标和成就颜色的提示，并播放普通或挑战成就音效。「天赐良机」「热门景点」「上天入地」在解锁前不会出现在导图中。

## 头像

- 所有预设头像已移除，头像统一来自 `avatars/` 文件夹。
- 直接打开 `avatars.html` 可以预览、选择头像；也可以从游戏主界面点「更换头像」打开。
- 浏览器不能自动扫描本地文件夹，所以：
  1. 在 `avatars/manifest.js` 里登记图片（适合部署到 GitHub Pages），或
  2. 在 `avatars.html` 里点「从文件夹导入」，选择 `avatars/` 文件夹（适合本地使用）。
- 导入的图片会压缩后保存在本机浏览器里；也可以直接「上传一张照片」。

## 昵称

- 每台设备第一次进入会要求输入一个**昵称**；之后跑步时昵称会显示在角色头顶，排行榜也只显示昵称。
- 昵称设置后可以点首页左上角放大的「昵称」按钮修改。
- **昵称在 30 天内最多修改 2 次**；首次设置不计入修改次数。
- 设置/修改昵称的弹窗会显示剩余修改次数和警告；次数用完后会显示下一次可修改的日期，并禁止继续保存。
- 修改次数记录在本机浏览器；清除浏览器数据会重置这个本地限制。

## 操作与其它

- 头像、昵称、模式、最高分、成就和本机排行榜会保存在当前浏览器本地。
- 排行榜分为「本机」和「全球」：本机只保存在当前浏览器；全球榜通过 Supabase 同步，同一网址下所有设备看到同一份记录。
- 本次更新会清空一次本机排行榜和最高分；全球榜通过新的记录时间起点隐藏旧记录，旧数据仍保留在数据库中。要彻底删除旧全球记录，可在 SQL Editor 运行：
  `delete from public.scores;`
- 每局结束会先写入本机，再自动尝试上传到全球榜；断网或上传失败时会进入待同步队列，下次打开排行榜/重新进入游戏时自动重试。
- 更新前已经存在的本机旧成绩不会自动上传；从这次更新后的新对局开始进入全球榜。
- 如果所在网络无法访问 `supabase.co`，全球榜会显示连接失败，切换到「本机」仍可查看本地成绩。
- 全球榜记录昵称、模式、分数、金币、距离、用时与日期；最高分仍按模式保存在本机。
- 无敌期间掉坑、地刺、飞行小怪等规则与普通小怪一致；困难/极限的受伤与回地无敌都是 0.8 秒。
- 所有场景、角色、金币、障碍和 UI 都是代码绘制的；头像除外。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、模式选择、头像预览、成就/排行榜弹层、HUD |
| `styles.css` | 菜单、弹窗、成就、排行榜、响应式布局 |
| `game.js` | Canvas 场景、角色、物理、模式规则、障碍、成就、音效与存档 |
| `avatars.html` | 独立头像选择页 |
| `avatars/` | 头像文件夹、`manifest.js` 清单与默认头像 |
| `previews/` | 菜单、游戏、暂停与排行榜效果图 |
