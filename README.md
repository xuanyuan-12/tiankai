# 超级马里奥 · 极速跑酷

一个不需要构建、打开即玩的 HTML5 马里奥风无尽跑酷小游戏。主角的头像可以随时更换，也可以上传自己的照片。

## 直接开始

双击 `index.html`，用现代浏览器（Chrome / Edge / Safari / Firefox）打开即可。

- 桌面端：`空格` 或 `↑` 跳跃，空中再按一次二段跳；`P` / `Esc` 暂停；`M` 静音。
- 手机端：横屏游玩，点击右下角的大跳跃键；空中再点一次二段跳。
- 主菜单和暂停菜单都可以换跑者。选择最后一格可上传照片，照片会变成游戏里主角的头。

## 玩法

- 自动向前奔跑，跳过水管、深坑和板栗仔。
- 从上方踩中板栗仔可以获得连击加分。
- 金币 +100 分；每收集 30 枚金币恢复一颗心。
- 共有 3 颗心。掉进深坑或撞到敌人会消耗一颗心，深坑会将你送回前方安全地面。
- 速度会随着距离逐渐加快，看看你能跑多远。
- 最高分、头像和声音偏好会保存在当前浏览器本地。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、弹层和 HUD |
| `styles.css` | 菜单、卡牌、弹窗、响应式布局 |
| `game.js` | Canvas 场景、角色绘制、跑酷物理、音效和头像逻辑 |

所有场景、角色、金币、水管和 UI 都是代码绘制的，没有图片或字体等外部依赖，离线可用。

## 小提示

- 上传照片时会在浏览器内自动居中裁剪成头像，不会上传到任何服务器。
- 上传后，再次点击“我的头像”卡片即可替换照片。
- 手机竖屏时会提示旋转设备，横屏才能看清整条跑道。
